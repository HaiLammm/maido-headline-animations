# ファーストビュー見出し　アニメーション見本

毎度おおきに商店 様のトップページ、ファーストビューの見出し
「MONTHLY WAGYU／今月の和牛／鹿児島県産 A5等級黒毛和牛」に使う動きの候補です。
どれも文字が左から右へ現れます。

**見本ページ：https://hailammm.github.io/maido-headline-animations/**

スマートフォンでもパソコンでもご覧いただけます。

- 画面下の ‹ › で見本を切り替え、「もう一度」で再生し直せます。
- 写真をタップしても再生し直せます。
- 下の一覧のカードをタップすると、上の大きな画面で再生します。
- 番号を付けたリンクで、その見本から開けます（例：…/maido-headline-animations/#05）。

## 見本の一覧

| No. | 名前 | 動き |
|---|---|---|
| 00 | 動きなし（現在） | 今のトップページと同じ、動きのない表示（比較用） |
| 01 | スライドイン | 各行が左からすっと滑り込む |
| 02 | ワイプ | 幕を開けるように、左から右へ文字が現れる |

| 04 | 斜めワイプ | 斜めの切り口が左から右へ走り、文字を切り出す |
| 05 | 帯リビール | 帯が左から伸びて右へ引き、その跡に文字が残る |
| 06 | 一文字ずつ | 一文字ずつ、左から順にふわっと現れる |
| 07 | ぼかしから | ぼやけた文字が、左から順にくっきりしていく |
| 08 | 流れ込み | 文字が左から勢いよく流れ込み、ぴたりと止まる |
| 09 | めくり | 一文字ずつ、カードをめくるように立ち上がる |
| 10 | タイプライター | カーソルとともに、一文字ずつ打ち込まれる |
| 11 | 光が走る | 表示のあと、金色の光が左から右へ文字をなぞる |

速さ・色・文字が現れる順番は、どの見本も調整できます。

## 技術メモ

- 動きはすべて CSS アニメーションです（外部ライブラリなし）。JavaScript は文字を一文字ずつに分けることと、見本の切り替えだけを行います。
- `css/text-animations.css` がアニメーション本体で、ストアのテーマにそのまま移せます。テーマでは、端末の「視差効果を減らす」設定がオンの方には動きを止め、文字をそのまま表示します。
- 読み上げソフトには、分割前の文章がそのまま読み上げられます。
- `css/demo.css` の見出し部分は、テーマのファーストビューと同じ文字サイズ・色・暗幕です。
- 写真はストアの CDN から読み込んでいます（このリポジトリには含みません）。
- 書体：Bodoni Moda と Yuji Syuku（どちらも SIL Open Font License 1.1、`fonts/licenses/`）。Yuji Syuku はこの見出しに使う文字だけに絞っています。
